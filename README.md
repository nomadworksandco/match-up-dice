# Match Up Dice

A party dice game: roll five dice, claim a round card, or let the house keep it.

Play solo against the house, or pass-and-play with friends. Optional online rooms for remote play.

## Clone and run

```bash
git clone https://github.com/nomadworksandco/match-up-dice.git
cd match-up-dice
npm install
npm run dev
```

Then open the local preview URL printed in the terminal.

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run typecheck` — TypeScript check

Built with Vite, React, and TanStack Start.
